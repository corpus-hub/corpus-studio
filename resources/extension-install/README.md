# Guided-install screenshots

Drop three PNGs here, named exactly:

    step-1-extensions-page.png    the chrome://extensions page
    step-2-developer-mode.png     the Developer mode switch, top-right
    step-3-load-unpacked.png      the "Load unpacked" button and folder picker

They are optional. Until a file exists the Settings panel renders that step's text
alone -- deliberately, so a fresh checkout shows followable instructions rather
than three broken images.

Only [a-z0-9-]+.png is served, and only from this directory.
